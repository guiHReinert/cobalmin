# Comando commit em Git

Comando usado para toda operação de commit.

Versionamento e alteração de códigos e arquivos em um repositório:

## Exemplos

- `git commit --amend -m <"MENSAGEM_COMMIT">` altera a descrição do último commit para `MENSAGEM_COMMIT`.
	- `git commit --amend` abre o editor do último commit dentro do terminal.
		- Digite *i* para editar o commit;
		- Digite *ESC* e *:wq* para editar e sair do editor.
