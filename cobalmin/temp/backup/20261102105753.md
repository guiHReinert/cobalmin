# GLUT

#cgr

Ou OpenGL Utilities Toolkit, é uma antiga biblioteca para a implementação de OpenGL para operações I/O e desenho de primitivas geométricas, agora descontinuada. Houveram tentativas de continuar a biblioteca original, como reprodução open-source FreeGLUT que adicionava poucas funções a mais.
