# Scikit-learn

Biblioteca Python especializada na análise preditiva de dados para machine learning. Foi desenvolvida a partir de *NumPy*, *SciPy* e *Matplotlib*.

## Exemplos

1. Proposta de workflow:

```python
import matplotlib.pyplot as plt
from sklearn.datasets import make_regression
from sklearn.linear_model import LinearRegression

# Gerando uma massa de dados.
x, y = make_regression(n_samples=200, n_features=1, noise=30)

# Mostrando no gráfico.
plt.scatter(x,y)
plt.show()

# Criação do modelo no modo padrão da função.
modelo = LinearRegression()
```

Agora que o modelo foi preparado, a amostra precisa passar pelo treinamento.

```python
# Representação de um treinamento.
# Retorna a população, logo, valores previstos de y neste caso.
y = modelo.predict(x)

# Os pontos muito distantes da reta gerada não representam bem a tendência dos dados.
plt.scatter(x)
plt.plot(x, y, color='red', lineWidth=3)
plt.show()
```
