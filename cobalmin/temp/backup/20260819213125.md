# Atividade de Criação de um Processador Simples

#AOC

## Enunciado 1

A partir do circuito em anexo, implemente as instruções:

* ADD - Soma X e Y e coloca o resultado em X (*X <- X + Y*).

Exemplo, coloca 5 em Y e 3 em X, após ADD X será 8: 
```
  LOAD 5
  XTO Y
  LOAD 3
  ADD
  XTO 0 ;coloca o resultado no registrador 0
```

* SUB - Subtrai X - Y e coloca o resultado em X
  * Faça complemento de 2 de Y e use o somador.
  * Apenas inclua: se a instrução for SUB --> (a) um desvio para Y passar por NOTs antes de chegar ao somador e (b) CI do somador deve ser nível alto.

## Enunciado 2

A partir do circuito em anexo, implemente as instruções:

* MLOAD - Busca para X o valor de uma posição de memória RAM usando endereçamento indireto. O endereço a ser buscado estará no registrador M.
* MSTORE - Grava de X para a memória na posição indicada por M.

Inclua um chip de RAM (4bits)
