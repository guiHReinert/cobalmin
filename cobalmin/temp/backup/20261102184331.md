# SQL - Operação INSERT

#ban

Insere uma nova tupla preenchida com dados em uma tabela.

## Sintaxe

As colunas e os valores de cada coluna precisam estar na mesma ordem da tabela.

```sql
INSERT INTO <TABELA>(<COLUNAS>) VALUES (<NOVOS_VALORES_EM_ORDEM>);
```
