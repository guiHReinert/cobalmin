# BFS - Busca em Largura

#teg

Percorre nível por nível do grafo e possui as mesmas estruturas auxiliares que a DFS.

**Pseudo-código**: Como o algoritmo se utiliiza de uma fila, mesmo que simples, existe um custo computacional a mais na adição de elementos nesta fila.

```hs
# Chamada:
BFS(grafo, raiz, MatAdj)

# Função:
BFS(G, v, M)
	marca[ ] = zeros
	# F é uma fila
	F = cria(Fila)
	marca[v] = 1
	print(v)
	insere(F, v)
	enquanto F não é vazia:
		para cada w adjacente à frente(F):
			se marca[w] = 0
				marca[w] = 1
				print(w)
				insere(F, w)
		remove(F)
```
