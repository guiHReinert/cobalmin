# Comandos para Branchs em Git

Comando usado para as principais operações referentes ao tratamento de branchs.

## Exemplos

- `git branch <NOME_BRANCH>` cria uma nova branch
- `git checkout <NOME_BRANCH>` muda para a branch `NOME_BRANCH`
	- **Alternativamente**: `git checkout -b <NOME_BRANCH>` cria e muda para uma nova branch
- `git fetch <REMOTO> <BRANCH>` coleta os commits do repositório `REMOTO` (usualmente tido como "origin") em `BRANCH`.
	- **Ex**: `git fetch origin main`
- `git merge <REMOTO/BRANCH>` atualiza o repositório local com os commits registrados na máquina na branch `REMOTO/BRANCH`.
	- **Ex**: `git merge origin/main`
- `git diff <BRANCH_LOCAL> <BRANCH_REMOTA>` lista as diferenças entre os commits de cada branch (pode-se também inverter a ordem);
	- **Ex**: `git diff main origin/main` ou `git diff origin/main main`
