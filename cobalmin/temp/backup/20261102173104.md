# Atomicidade de Dados em SQL

#ban

Cada valor da tabela deve ser indivisível, irredutível. Por exemplo, uma tabela de endereço composto por rua, casa ou apartamento, número, cidade, estado e país, deve ter cada um de seus campos separados em outras colunas que os contenha individualmente.

## Exemplos

1. Transferência dos endereços da tabela “Usuarios” para campos segmentados.

```sql
-- Adicionar colunas de endereço à tabela "Usuarios"
ALTER TABLE Usuarios
ADD rua VARCHAR(100),
ADD numero VARCHAR(10),
ADD cidade VARCHAR(50),
ADD estado VARCHAR(50);

-- Copia os dados da tabela original para a nova tabela
UPDATE usuarios
SET rua = SUBSTRING_INDEX(SUBSTRING_INDEX(endereco, ',', 1), ',', -1),
    numero = SUBSTRING_INDEX(SUBSTRING_INDEX(endereco, ',', 2), ',', -1),
    cidade = SUBSTRING_INDEX(SUBSTRING_INDEX(endereco, ',', 3), ',', -1),
    estado = SUBSTRING_INDEX(endereco, ',', -1);

-- Exclusão da coluna "endereco" da tabela original
ALTER TABLE usuarios
DROP COLUMN endereco;
```
