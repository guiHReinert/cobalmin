# Parâmetros de Funções em Python

#python

Uma função pode ser declarada e executada por diversas maneiras distintas, onde `/`, `*`, `*args` e `kwargs` são parâmetros especiais:

1. Caso os parâmetros de uma função não sejam especificados durante a sua execução, `val1`, `val2`, `valn`, etc serão utilizados por padrão pela função:

```python
def func(arg1=val1, arg2=val2,..., argn=valn):
	...
```

2. Uma função pode ser executada com parâmetros posicionais, em sequência, ou numa ordem arbitrária com o uso de *keywords*, logo como parâmetros nomeados:

```python
def func(arg1, arg2, arg3):
	...

func(coisa1, coisa2, coisa3)                # posicionais
func(arg2=coisa2, arg3=coisa3, arg1=coisa1) # nomeados
```

3. Positional Only: Todos os parâmetros declarados antes de `/` são obrigatoriamente posicionais:

```python
def func(pos1, pos2, pos3, /, opc1, opc2, ...):
	...
``` 

4. Keyword Only: Todos os parâmetros declarados após `*` são obrigatoriamente nomeados:

```python
def func(opc1, opc2, *, nom1, nom2, ...):
	...
```

5. A declaração de uma função suporta uma quantidade indeterminada de parâmetros isolados, uma tupla indicada por `*args` e um dicionário `kwargs`. Tanto `args` quanto `kwargs` são nomes arbitrários e podem ser substituidos por qualquer outro. Abaixo estão duas possibilidades de declaração de funções que se utilizam dos dois parâmetros especiais acima, os quais também podem ser declarados juntos de `/` e `*`, respeitada a lógica de cada um:

```python
## pos1, pos2 e pos3 são positional only.
## A partir do quarto parâmetro posicional *args é alimentado.
## A partir do primeiro parâmetro nomeado kwargs é alimentado.
def func1(pos1, pos2, pos3, *args, kwargs):
	args   # (a, b, c, d,...)
	kwargs # {k1:v1, k2:v2, k3:v3,...}
	...

## Todo parâmetro posicional alimenta *args.
## Os 3 primeiros parâmetros nomeados atribuem nom1, nom2 e nom3.
## A partir do quarto parâmetro nomeado kwargs é alimentado.
def func2(*args, nom1, nom2, nom3, kwargs):
	...
```
