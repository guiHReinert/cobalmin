# Registrador

#aoc

Sequências de flip-flops D que recebem valores de entrada e os transferem para a saída apenas depois de um pulso de clock.  Cada entrada é conectada a uma respectiva saída que emite exatamente o valor recebido. Útil para organizar a recepção e emissão e dados numa ordem previsível e de preferência exata.

Cada dispositivo de memória é formado entre outros por registradores. Dentro de um processador se localizam registradores especializados em funções específicas para o tratamento de dados.
