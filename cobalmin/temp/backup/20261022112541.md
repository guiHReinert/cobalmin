# Operadores Aritméticos da Linguagem C

Realizam as operações matemáticas básicas entre valores numéricos na linguagem C.

Lexicamente todo número inteiro é também um float.

|Operador|Símbolo| Sintaxe | Observação | 
|---|---|--|--|
|Adição|`+`| `INTEIRO + INTEIRO` |  | 
|Sutração|`-`| `INTEIRO - INTEIRO` |  | 
|Multiplicação|`*`| `INTEIRO * INTEIRO` |  | 
|Divisão inteira|`/`| `FLOAT / FLOAT` |  |
|Resto da Divisão|`%`| `FLOAT % FLOAT` | Útil para definir se o número é par |
| Adição Unária |+|  `+INTEIRO`  |     Promove o tipo do valor para `int` ou `unsigned int` caso for `short`    |
|  Subtração Unária |-|  `-INTEIRO`  |     Promove e inverte o sinal do valor    |
| Incremento |++|  `INTEIRO++`  | Aumenta o valor em 1 a cada chamada |
| Decremento |--|  `INTEIRO--`  | Diminui o valor em 1 a cada chamada |
