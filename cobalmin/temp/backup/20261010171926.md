# Função FIRST()

#com

Seja $\alpha$ uma cadeia qualquer de símbolos gramaticais, $FIRST(\alpha)$ representa os conjuntos de terminais que começam as cadeias derivadas a partir de $\alpha$.

Se $\alpha\,^*\Rightarrow\epsilon$ então $\epsilon$ também é um elemento de $FIRST(\alpha)$.
