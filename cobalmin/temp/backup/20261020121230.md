# Símbolo

#lfa

Ou letra, caractere, é uma entidade abstrata básica, sem definição formal, usada como base para vários formalismos matemáticos. Um conjunto finito de símbolos é chamado de alfabeto e uma sequência de símbolos é chamada de palavra.
