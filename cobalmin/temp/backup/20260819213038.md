# Dispositivos Gráficos

#cgr

## Dispositivos de Entrada

Para a entrada de dados posicionais em 2D ou 3D:

- Teclado;
- Mouse convencional/siamês;
- Mesa digitalizadora;
- Joystick/Manche;
- Mouse de giro;
- Trackball;
- Magellan 3D controller (mouse 3D);
- Handle bar;
- Sistemas de feedback tátil;
- Datagloves;

## Dispositivos de Saída

- Projetor;
- Multi monitor;
- Monitores em diferentes formatos;
- Visio station;
- Mesas interativas;
- Immersa desk;
- Workwall;
- Personal monitor;
- Tablet/Smartfone para RA;
- HMD (head mounted display), como o oculus rift;
- Caverna;
