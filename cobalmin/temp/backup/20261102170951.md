# Chave Primária em SQL

#ban

Identifica exclusivamente cada dado (ID) e não pode ser nulo. Elas podem ser **simples** (uma única coluna) ou **composta** (duas ou mais colunas). 

- **Constraint**: `PRIMARY KEY`.

## Exemplos
```sql
-- Tabela "usuarios"
-- "INT AUTO_INCREMENT" configura a coluna para ela automaticamente criar o ID do novo registro 1 valor maior que o anterior. Logo, as novas inserções não precisam mais indicar o valor da chave.
ALTER TABLE usuarios
MODIFY COLUMN id INT AUTO_INCREMENT, ADD PRIMARY KEY (id);

-- Tabela "destinos"
ALTER TABLE destinos
MODIFY COLUMN id INT AUTO_INCREMENT, ADD PRIMARY KEY (id);

-- Tabela "reservas"
ALTER TABLE reservas
MODIFY COLUMN id INT AUTO_INCREMENT, ADD PRIMARY KEY (id);
```
