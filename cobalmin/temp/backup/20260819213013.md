# Árvore

#eda2

Tipo de **grafo** ordenado centrado na hierarquia entre seus nodos.

Organizam os seus elementos por meio de **ramos**/**subárvores**, e a ponta de cada ramo (ou seu último elemento), a qual não possui nenhum valor ou elemento, é chamada de **folha**. O primeiro nodo (nível da árvore) é chamado de **raiz** e se ramifica para todos os outros demais. Cada ramificação pode ser interpretada como uma subárvore, uma outra árvore completamente separável.

Cada nodo comumente contém um único dado, valor ou elemento, mas podem existir árvores com nodos contendo mais de um valor.

**Grau da Árvore**: São contabilizadas as arestas que saem de um nodo. O maior grau dentre todos os nodos de uma árvore caracterizará o grau desta árvore.

**Nível de um Nodo**: A raiz de uma árvore tem nível 0 . Se um nodo tem nível $k$, seus filhos tem nível $k+1$.

**Caminho**: Sequência de nodos distintos ligados pela relação de pai e filho, sendo o comprimento de um caminho a quantidade de nodos percorridos. Existe um único caminho entre a raiz e qualquer nó.

**Profundidade**: Comprimento do caminho entre a raiz e a folha mais distante.

**Altura**: Caminho que possui a maior quantidade de nodos, logo a profundidade da árvore pode ser uma opção para essa medida.

**Largura**: Nível da árvore com a maior quantidade de nodos.

**Floresta**: Coleção de árvores. (???)

## Árvore B

Árvore autobalanceada para dados classificados com acesso sequencial ou aleatório/pesquisa. Não é uma árvore binária, mas é entendida como a generalização de um árvore binária justamente pela ramificação considerar que os nodos na esquerda devem ser menores, enquanto os da direita devem ser maiores de alguma forma.

**Ordem**: Estabelecida por: maior ou igual ao menor número de registros nos nodos da árvore, e o seu dobro deve ser menor ou igual ao maior número de registros da árvore.

O número máximo de filhos de um nodo é igual ao número máximo de chaves + 1

Cada nodo é uma sequência de registros listados. Em um mesmo nodo tem-se um registro mais à esquerda e outro mais à direita. Uma ramificação deve considerar os registros extremos e os internos de um mesmo nodo:

- **Esquerda**: A maior chave do nodo filho deve ser menor que a menor chave do pai;
- **Direita**: A menor chave do filho deve sr maior que a maior chave do pai;
- **Centro**: As chaves extremas do filho devem estar dentro do intervalo do pai.

**Complexidade**:

- Pesquisa: $O\log(n)$;
- Inserção: $O\log(n)$;
- Remoção: $O\log(n)$.

**Estrutura da Árvore**:
```c
typedef struct no {
    int total;
    int* chaves;
    struct no** filhos;
    struct no* pai;
} No;
typedef struct arvoreB {
    No* raiz;
    int ordem;
    } ArvoreB;
```
**Criar uma árvore B com uma ordem predefinida**:
```c
ArvoreB* criaArvore(int ordem) {
    ArvoreB* a = malloc(sizeof(ArvoreB));
    a->ordem = ordem;
    a->raiz = criaNo(a);
    return a;
}
```
- **Nodo**:
```c
No* criaNo(ArvoreB* arvore) {
    int max = arvore->ordem * 2;
    No* no = malloc(sizeof(No));
    
    no->pai = NULL;
    
    no->chaves = malloc(sizeof(int) * (max + 1));
    no->filhos = malloc(sizeof(No) * (max + 2));
    no->total = 0;
    
    for (int i = 0; i < max + 2; i++)
        no->filhos[i] = NULL;
    
    return no;
}
```

### Pesquisa

#### Percorrer a Árvore no Nodo
```c
void percorreArvore(No* no, void (visita)(int chave)) {
    if (no != NULL) {
        for (int i = 0; i < no->total; i++){
            percorreArvore(no->filhos[i], visita);
            visita(no->chaves[i]);
        }
        percorreArvore(no->filhos[no->total], visita);
    }
}
```
#### Busca Binária
```c

int pesquisaBinaria(No* no, int chave) {
    int inicio = 0, fim = no->total - 1, meio;
    while (inicio <= fim) {
        meio = (inicio + fim) / 2;
        if (no->chaves[meio] == chave) {
            return meio; //encontrou
        } else if (no->chaves[meio] > chave) {
            fim = meio - 1;
        } else {
            inicio = meio + 1;
        }
    }
    return inicio; //não encontrou
}
```
#### Buscar uma Chave
```c

int localizaChave(ArvoreB* arvore, int chave) {
    No *no = arvore->raiz;
    while (no != NULL) {
        int i = pesquisaBinaria(no, chave);
        if (i < no->total && no->chaves[i] == chave) {
            return 1; //encontrou
        } else {
            no = no->filhos[i];
        }
    }
    return 0; //não encontrou
}
```
#### Buscar um Nodo
```c
No* localizaNo(ArvoreB* arvore, int chave) {
    No *no = arvore->raiz;
    while (no != NULL) {
        int i = pesquisaBinaria(no, chave);
        if (no->filhos[i] == NULL)
            return no; //encontrou nó
        else
            no = no->filhos[i];
    }
    return NULL; //não encontrou nenhum nó
}
```

### Balanceamento

**Trade-Off de Balanceamento**: Quanto maior o tamanho pré-determinado da árvore menos *overflows* serão gerados, porém mais espaço na memória será ocupado.

**Verificar se houve transbordo (overflow) em um nó**:
```c
int transbordo(ArvoreB *arvore, No *no) {
    return no->total > arvore->ordem * 2;
}
```

#### Adição

Adiciona a chave -> verifica se a limitação da ordem da árvore foi respeitada (não superou o máximo (overflow)) ? adiciona a chave : divide o nodo pela metade e gera outros dois. A chave então é inserida no pai desses dois novos nodos.

**Adicionar nova chave na árvore**:
```c
void adicionaChave(ArvoreB* arvore, int chave) {
    No* no = localizaNo(arvore, chave);
    adicionaChaveRecursivo(arvore, no, NULL, chave);
}
```
**Adicionar chave em um nó**:
```c
void adicionaChaveNo(No* no, No* direita, int chave) {
    int i = pesquisaBinaria(no, chave);
    for (int j = no->total - 1; j >= i; j--) {
        no->chaves[j + 1] = no->chaves[j];
        no->filhos[j + 2] = no->filhos[j + 1];
    }
    no->chaves[i] = chave;
    no->filhos[i + 1] = direita;
    no->total++;
}
```
**Adicionar nova chave na árvore (cont.)**:
```c
void adicionaChaveRecursivo(ArvoreB* arvore, No* no, No* novo, int chave) {
    adicionaChaveNo(no, novo, chave);
    if (transbordo(arvore, no)) {
        int promovido = no->chaves[arvore->ordem];
        No* novo = divideNo(arvore, no);
        if (no->pai == NULL) {
            No* raiz = criaNo(arvore);
            raiz->filhos[0] = no;
            adicionaChaveNo(pai, novo, promovido);
            no->pai = raiz;
            novo->pai = raiz;
            arvore->raiz = raiz;
        } else
            adicionaChaveRecursivo(arvore, no->pai, novo, promovido);
    }
}
```
**Split: Divisão chaves de um nó em um novo nó**:
```c
No* divideNo(ArvoreB* arvore, No* no) {
    int meio = no->total / 2;
    No* novo = criaNo(arvore);
    novo->pai = no->pai;
    for (int i = meio + 1; i < no->total; i++) {
        novo->filhos[novo->total] = no->filhos[i];
        novo->chaves[novo->total] = no->chaves[i];
        if (novo->filhos[novo->total] != NULL) novo->filhos[novo->total]->pai = novo;
        novo->total++;
    }
    novo->filhos[novo->total] = no->filhos[no->total];
    if (novo->filhos[novo->total] != NULL) novo->filhos[novo->total]->pai = novo;
    no->total = meio;
    return novo;
}
```
