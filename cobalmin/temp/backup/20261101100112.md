# Linguagem Decidível

#tec

Ou Turing-Decidível ou Recursiva. É uma linguagem

$$
L(M) = L_\text{g}\,\text{e}\,\text{LOOP}(M) = \varnothing 
$$

da máquina de turing $M$. Toda linguagem decidível é reconhecível.
