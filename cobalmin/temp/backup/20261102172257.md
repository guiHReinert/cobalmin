# Índices em SQL

#ban

`EXPLAIN`: Detalha as variáveis envolvidas em uma busca, como o número de linhas percorridas e os índices declarados.

**Ex**:
```sql
-- Toda Maria
EXPLAIN SELECT * FROM usuarios WHERE nome = "Maria";

-- Toda Maria que possui reserva
EXPLAIN SELECT * FROM usuarios us INNER JOIN reservas rs
ON us.id = rs.id_usuario WHERE nome = "Maria";

-- Cada nome terá um índice "idx_nome" associado, o que aumentará a performance da consulta pelo nome "Maria"
CREATE INDEX idx_nome ON usuarios (nome);
EXPLAIN SELECT * FROM usuarios WHERE nome = "Maria";
```
