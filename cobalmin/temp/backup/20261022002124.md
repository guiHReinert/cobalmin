# Tempo de Intervalo no Treino de Musculação

#musculacao

**Treinamento para Força:** Recuperação total entre as séries e alta intensidade/carga.

- Min de 2-3min para exercícios leves, como rosca direta.
- Min de 3-5min para os pesados, como levantamento terra, agachamento e barra fixa.

**Treinamento para RML:** Recuperação parcial entre as séries para treinar a musculatura a aumentar a sua capacidade de glicolítica, consequentemente avermelhando mais os músculos (aumento de oxigenação pela maior passagem de sangue).

- Max de 30-40s para exercícios leves e 45 s para pesados.

**Treinamento para Hipertrofia:** Foco intermediário entre os tipos de treino.

- 1min para exercícios leves, como rosca direta, tríceps pulley e crucifixo.
- 2min para pesados.

Pode utilizar o mesmo tempo de intervalo entre as séries para entre exercícios.
