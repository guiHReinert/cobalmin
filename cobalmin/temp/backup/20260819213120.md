# Organização de Arquivos

#aoc
#eda2

UM arquivo possui atributos que podem variar em nome, tipo e comprimento. Os atributos contidos em chaves, as quais listam sequências de um ou mais atributos. Elas podem primárias ou secundárias:

- **Chave Primária:** identifica exclusivamente cada registro do arquivo
- **Chave Secundária:** identifica, geralmente por meio de índices, de modo auxiliar os registros de um arquivo. Elas podem se repetir entre arquivos.

**Registro Exaustivo:** Uma chave aponta para um único registro diretamente.
**Registro Seletivo:** Uma chave aponta para uma lista de registros.

**Pesquisa em Memória Principal:**

- Pesquisa sequencial (linear) ou com sentinela
- Pesquisa binária
- Pesquisa por interpolação
- Pesquisa direta (hashing)

**Pesquisa em Memória Secundária:**

- [[20261012134630|Árvore Binária]]
- Árvore B, B+ e B*
- Árvores Trie e Patrícia

## Estratégias de Organização:

### Arquivo Sequencial Simples

Os registros são dispostos sem seguir uma ordem de chaves e de maneira sequencial. Fácil de implementar, inclusive para organizar a medida que eles são gerados, mas ineficiente para algoritmos de busca.

### Arquivo Sequencial Ordenado

Os registros são postos em sequência e são ordenados por meio de chaves primárias (**chaves de ordenação**) em ordem crescente. Uma vez que as chaves são uniformes a operação de busca delas se torna mais eficiente, porém a chave de acesso utilizada precisa **coincidir** com a chave de ordenação. Outra desvantagem é que sempre que haver uma operação de inserção, remoção ou alteração poderá ser necessário **reorganizar** as chaves.

### Arquivo Sequencial Indexado

Cada arquivo é composto por **3 regiões**: Área de Índices, área primária (principal) e área de excedentes (overflow), funcionando como um meio termo entre o sequencial e o indexado.

- **índices:** Apontam para segmentos do arquivo. Índices de múltiplos níveis apontam para outros indices, ou seja, carregam mais de um índice para cada índice, até que se consegue chegar no registro procurado.
- **Área Primária:** Os dados registrados propriamente.
- **Área de Extensão:** Todo novo registro é armazenado nesta área de modo **encadeado** até que seja efetuada uma organização. Sua função é **não sobrecarregar** o sistema com o processo de reorganizar os índices a cada nova inserção, então essa organização é feita a partir de momento que um marco, como por exemplo 75% da capacidade dessa região for atingida, seja alcançado.

### Arquivo Indexado

**Não tem organização espacial** definida, mas seus registros relacionados por um ou mais índices suporta múltiplas chaves de acesso para os registros. As inserções são mais eficientes, porém o acesso sequencial sai prejudicado.

### Arquivo Direto

Não usa índices e precisa da implementação de uma **função de hashing**: o endereço do registro é calculado a partir do valor da chave. Os registros não são ordenados e há o risco de serem geradas **colisões**, quando duas chaves geram o mesmo endereço, porém o acesso aleatório de seu registros é o mais rápido.

### Arquivo Invertido

Complementa as outras estratégias adicionando **listas invertidas** ligadas a chaves secundárias. Em vez de buscar por chave primária, você busca por um atributo qualquer (ex: departamento = "C") e obtém diretamente a lista de todos os registros correspondentes.
