# Cor

#cgr

Propriedade de percepção que permite diferenciar diferentes energias luminosas determinada pelo comprimento de onda emitido por um objeto ou uma fonte qualquer. Um objeto

- possui uma determinada cor pois ele absorve todas as cores, com exceção desta;
- é branco ao refletir todas as cores;
- é preto ao absorver todas as cores.
