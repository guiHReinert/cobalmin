# Tratabilidade de Problemas

#cal

Problemas tratáveis são aqueles resolvíveis por algoritmos deterministas e que executam em tempo polinomial, ou seja, $1 < \log < \log(n) < n < n\log(n) < n^k$, e são categorizados com base na sua eficiência. Quaisquer outros problemas que não possuem algoritmos deterministas que os resolvam em tempo polinomial são intratáveis, como os de complexidade $2^n < n!$.
