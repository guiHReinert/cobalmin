# DFS - Busca em Produndidade

#teg

É chamada por uma lista de vértices marcados, para não visitar um mesmo vértice duas vezes, e um vértice raiz. Percorre todo o grafo priorizando a chegada em um vértice que não possua adjacências com nenhum outro vértice não marcado. Depois, o algoritmo inicia outra iteração tendo o vértice pai como a nova raiz, e assim por diante, recursivamente, até que todo o grafo seja marcado ou outra condição seja satisfeita.

**Pseudo-código**: Aqui espera-se que o valor dos vértices seja um inteiro positivo, logo, o vetor de marcações será binário e a posição $n$ deste vetor será 1 para um vértice de valor $n$.

```hs
# Chamada
DFS(grafo, raiz, MatAdj, vetMarca)

# Função
DFS(G,v, M, marca)
	marca[v] = 1
	print(v)
	para cada w adjacente a v
		se marca[w] = 0
			DFS(G, n, M, marca)
		senao
			retorna
	retorna
```

**Algoritmo em C Para Uma Lista de Adjacências Encadeada**:

```c
void DFS_G(Grafo* grafo, int raiz, int* vet_marca){
    vet_marca[raiz] = 1;
    // printf("%d ", raiz);
    Vertice* walker = grafo->lista[raiz].posterior;
    while(walker != NULL){
        if(!vet_marca[walker->valor]){
            DFS_G(grafo, walker->valor, vet_marca);
        }
        walker = walker->posterior;
    }
}
```
