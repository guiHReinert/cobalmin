# Árvore de Derivação

#lfa

É uma árvore que representa a derivação de uma palavra formada a partir de uma gramática livre de contexto.

- A raiz da árvore de derivação é o símbolo inicial da GLC;
- Os vértices interiores são variáveis;
- Os vértices folha são símbolos terminais, pois concluem a formação da palavra;
