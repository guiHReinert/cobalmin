# Comandos para Repositórios em Git

Inicialização e edição de *repositórios*:

- `git init` inicializa a pasta atual como um repositório *Git* vazio.
- `git clone <URL> <NOME_LOCAL>` clona o repositório contido no link `URL` para a pasta atual. De modo opcional pode-se alterar o nome da pasta gerada para`NOME_LOCAL`.
- `git remote add origin <URL>` conecta o reposotório *local* atual com um repositório *remoto* de link `URL`.

Caso queira-se remover o gerenciamento de uma pasta pelo git (como a inicialização não intencionada de um repositório), existem comandos que removem um diretório e/ou em parte ou totalmente todo o seu conteúdo. Pode-se optar pelo uso estes comandos, ou remover manualmente a pasta *.git* para remover o gerenciamento:

- `rm -rf .git` remove forçadamente e recursivamente o repositório local com ***TODO*** o seu conteúdo.
