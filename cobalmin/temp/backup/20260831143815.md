### Seleção

1. Buscar os dados dos pacientes que estão com sarampo.

```sql
σ doenca = 'sarampo' (Pacientes)
```

2. Buscar os dados dos médicos ortopedistas com mais de 55 anos.

```sql
σ especialidade = 'ortopedia' ∧ idade > 55 (Medicos)
```

3. Buscar os dados de todas as consultas, exceto aquelas marcadas para os médicos com código 46 e 79.

```sql
σ codm ≠ 46 ∨ codm ≠ 79 (Consultas)
```

4. Buscar os dados dos ambulatórios do quarto andar. Estes ambulatórios devem ter capacidade igual a 50 ou número superior a 10.

```sql
σ andar = 4 ∧ (capacidade = 50 ∨ capacidade > 10)(Ambulatorios)
```

### Projeção

1. Buscar o nome e a especialidade de todos os médicos

```sql
π nome, especialidade (Medicos)
```

2. Buscar o número dos ambulatórios do terceiro andar

```sql
π nroa (σ andar = 3 (Ambulatorios))
```

3. Buscar os códigos dos médicos e as datas das consultas para os pacientes com os códigos 122 e 725

```sql
π codm, data (σ codp = 122 ∨ codp = 725 (Consultas))
```

4. Buscar os números dos ambulatórios com capacidade superior a 5, exceto aqueles do segundo e quarto andares

```sql
π nroa (σ capacidade > 5 ∧ andar ≠ 2 ∧ andar ≠ 4(Ambulatorios))
```

### Produto Cartesiano

1. Buscar o nome dos médicos que têm consulta marcada e as datas das suas consultas. 

```sql
π Medicos.nome, Consultas.data (σ (Medicos.codm = Consultas.codm)(Medicos x Consultas))
```

2. Buscar o número e a capacidade dos ambulatórios do quinto andar e o nome dos médicos ortopedistas que atendem neles.

```sql
π Ambulatorios.nroa, Ambulatorios.capacidade, Medicos.nome (
    σ (
        Ambulatorios.andar = 5
        ∧ Ambulatorios.nroa = Medicos.nroa
        ∧ Medicos.especialidade = 'ortopedia'
    )(Medicos x Ambulatorios))
```

3. Buscar, para as consultas marcadas para o período da manhã (7hs-12hs) do dia 25/09/06, o nome do médico, o nome do paciente e a data da consulta.

```sql
π Medicos.nome, Pacientes.nome, Consultas.data (
	σ Consultas.codp = Pacientes.codp
    ∧ Consultas.codm = Medicos.codm
    ∧ Consultas.data = date ('2006-09-25')
    ∧ Consultas.hora > '07:00:00'
    ∧ Consultas.hora < '12:00:00' (
        Consultas x Medicos x Pacientes
    )
)
```

4. Buscar o nome e o salário dos funcionários de Florianópolis e Palhoça que estão internados como pacientes e têm consulta marcada com psiquiatras.

```sql
π Funcionarios.nome, Funcionarios.salario (
	σ Funcionarios.cpf = Pacientes.cpf
	∧ Pacientes.codp = Consultas.codp
	∧ Consultas.codm = Medicos.codm
	∧ Funcionarios.cidade = 'Florianopolis'
	∨ Funcionarios.cidade = 'Palhoca'
	∧ Medicos.especialidade = 'psiquiatria' (
		Consultas x Funcionarios x Pacientes x Medicos
	)
)
```

2. Buscar o nome e o CPF dos funcionários que recebem salários iguais ou inferiores ao salário do funcionário com CPF 1001.

```sql
F5 = π codf, salario (
```


### União, Diferença e Intersecção

1. Buscar o nome e CPF dos médicos e dos pacientes cadastrados no hospital.

```sql
π Medicos.nome, Medicos.cpf (Medicos)
∪
π Pacientes.nome, Pacientes.cpf (Pacientes)
```

2. Buscar o nome, CPF e idade dos médicos, pacientes e funcionários que residem em Florianópolis.

```sql
π nome, cpf, idade (σ cidade = 'Florianopolis' (Medicos))
∪
π nome, cpf, idade (σ cidade = 'Florianopolis' (Pacientes))
∪
π nome, cpf, idade (σ cidade = 'Florianopolis' (Funcionarios))
```

3. Buscar o nome e CPF dos funcionários que recebem salários abaixo de R$ 500,00 e não estão internados como pacientes.

```sql
π nome, cpf (σ salario < 500 (Funcionarios))
-
π Funcionarios.nome, Funcionarios.cpf (
	σ Pacientes.cpf = Funcionarios.cpf (
		Funcionarios x Pacientes
	)
)
```

4. Buscar o número dos ambulatórios onde nenhum médico dá atendimento.

```sql
π nroa (Ambulatorios)
-
π Ambulatorios.nroa (
	σ Ambulatorios.nroa = Medicos.nroa (
		Ambulatorios x Medicos
	)
)
```

5. Buscar o nome e CPF dos funcionários de Florianópolis que estão internados como pacientes.

```sql
π nome, cpf (σ cidade = 'Florianopolis' (Funcionarios))
∩
π nome, cpf (Pacientes) 
```

6. Buscar o nome e CPF dos médicos pediatras que não atendem nos ambulatórios 101 e 102, e estão internados como pacientes sofrendo de gastrite.

```sql
π nome,cpf (
	σ
	especialidade = 'pediatria'
	∧ (nroa ≠ 101 ∧ nroa ≠ 102) (
		Medicos
	)
)
∩
π nome,cpf (σ doenca='gastrite' (Pacientes))
```

### Junção Natural

1. Buscar o número e a capacidade dos ambulatórios do quinto andar e o nome dos médicos que atendem neles.

```sql
π nroa, capacidade, nome (σ andar = 5 (Ambulatorios) ⨝ Medicos)
```
, equivalente a

```sql
π Medicos.nroa,capacidade,nome (σ andar = 5 ∧ Ambulatorios.nroa = Medicos.nroa (Ambulatorios x Medicos))
```

2. Buscar o nome e o salário dos funcionários de Florianópolis e Palhoça que estão internados como pacientes e têm consulta marcada em 20/10/2006.

```sql
π Funcionarios.nome,salario (
	σ cidade = 'Florianopolis'
	∨ cidade = 'Palhoca'(Funcionarios)
	⨝ Pacientes
	⨝ data = date('2006-10-20') Consultas
)
```

3. Buscar o número e o andar dos ambulatórios onde nenhum médico dá atendimento.

```sql
π nroa, andar (Ambulatorios)
- π nroa, andar (Ambulatorios ⨝ Medicos)
```

4. Buscar o número dos ambulatórios que estão no mesmo andar do ambulatório 101 e possuem capacidade superior à capacidade dele.

```sql
A1 = π andar(σ nroa = 101 (Ambulatorios))

-- Seleciona o ambulatorio de nroa 101 e o renomeia, e a junção natural compara ele com os demais ambulatórios também renomeados e com as condições pedidas
π A.nroa (
	σ A101.nroa = 4 (
		ρ A101 (Ambulatorios)
	)
	⨝ A.andar = A101.andar ∧ A.capacidade > A101.capacidade (ρ A Ambulatorios)
)
```

### Junções Externas (Outer Joins)

1. Buscar os dados de todos os médicos e, para aqueles que têm consultas marcadas, mostrar os dados de suas consultas.

```sql
Medicos ⟕ Consultas
```

2. Buscar os números de todos os ambulatórios e, para aqueles ambulatórios nos quais médicos dão atendimento, exibir o código e o nome dos médicos associados.

```sql
Ambulatorios ⟕ π codm, nome, nroa (Medicos)
```

3. Mostrar em uma relação o CPF e nome de todos os pacientes e de todos os médicos, apresentando estes dados de forma relacionada para aqueles que possuem consultas marcadas.

```sql
-- PROVAVELMENTE ERRADA
-- LOJ para preservar os pacientes -> FOJ para preservar os pacientes sem relacao com os medicos, mas ambos tem consultas em comum
π Pacientes.cpf, Pacientes.nome, Medicos.cpf, Medicos.nome (
  Pacientes ⟕ Consultas ⟗ Medicos
)
```

### Divisão

1. Buscar o código dos pacientes que têm consultas marcadas com todos os médicos.

```sql
(π codp, codm (Consultas)) ÷ (π codm (Medicos))
```

2. Buscar o nome e o CPF dos médicos que têm consultas marcadas com todos os pacientes.

```sql
π nome, cpf(
	Medicos ⨝ (
		(π codm, codp (Consultas))
		÷
		(π codp (Pacientes))
		)
)
```

3. Buscar o nome e o CPF dos pacientes que têm consultas marcadas com todos os médicos ortopedistas que atendem nos ambulatórios do primeiro andar.

```sql
-- Nao incluir as colunas de exportação da pesquisa na divisão
π nome, cpf (
    Pacientes ⨝ (
        (π codp, codm (Consultas))
        ÷
        (π codm (
            σ especialidade = 'ortopedia' ∧ andar = 1
            (Medicos ⨝ Ambulatorios)
        ))
    )
)
```

4. Todos os médicos ortopedistas dão atendimento no mesmo ambulatório? Em caso afirmativo, buscar o número e o andar deste ambulatório.

```sql
-- Organizar o dividendo e o divisor de modo que sejam compatíveis, mesmo que aparentemente redundantes
π nroa, andar, codm (σ especialidade = 'ortopedia' (Medicos ⨝ Ambulatorios))
÷
π codm (σ especialidade = 'ortopedia' (Medicos))
```
