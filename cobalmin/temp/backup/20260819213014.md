Última camada de comunicação entre o processador e o usuário.  O projeto do processador define os formatos e os tipos de **instruções de máquina** utilizadas, acompanhadas pelo *opcode* e de um parâmetro (origem do operando ou destino do resultado). Cada processador tem os seus registradores próprios e um mesmo código em Assembly é, portanto, específico para tal processador.

Um código em Assembly é composto por **instruções** e **rótulos**, capazes de criar loops ou acessar outras regiões do código:
```
	INSTRUÇÃO 1
	INSTRUÇÃO 2
RÓTULO 1:
	INSTRUÇÃO dentro do rótulo
```

O código é estrito em Assembly via texto e depois montado/compilado por um **montador** ou ***assembler*** para um código binário útil ao processador.

## Instruções

`CALL RÓTULO`: Acessa `RÓTULO`, e depois que `RÓTULO` terminar todas as suas instruções, o programa volta para a instrução seguinte a essa chamada. Caso `RÓTULO` possua outros rótulos associados, estes também deverão terminar as suas instruções para que o programa retorne à região original.

`JMP RÓTULO`: Acessa `RÓTULO` sem voltar para a linha depois da chamada.

`RET`: Retorna para a instrução posterior à chamada de `RÓTULO`.

### Endereçamento

Semelhante à aritmética e lógica de ponteiros em [[20260819213021|C]]. Utiliza a instrução `LD` para registrar o valor/endereço.

**Imediato**: `LD REGISTRADOR, VALOR` registra diretamente o valor no registrador apontado;

**Direto(Absoluto)**: `LD REGISTRADOR, (VALOR)` registra o endereço da memória apontada para o registrador;

**Indireto por Registrador**: `LD REGISTRADOR, (REGISTRADOR)` registra o valor contido no endereço de outro registrador;

**Por Registrador**: `LD REGISTRADOR, REGISTRADOR`: "O operando está num registrador";

**Indexado**: O endereço de um operando é dado por um registrador  base + um deslocamento. Ex:

- `LD A, (B-c)` registra o valor da memória de endereço `B-c`, ou seja, do registrador `B` em `c` posições a menos, no registrador `A`;
- `LD (Y+z), X` registra o valor `X` no registrador de endereço `Y+z`.

**Relativo**: Específico para saltos. Ex: `JMP LOOP` gera um salto incondicional relativo.

### Exemplos 

#### Z80 no MOODLE

```c
LD A, 1            ; carrega 1 em A
LD HL, $100        ; carrega 0x100 no registrador HL
LD (HL), A         ; escreve A na posição de memória apontada por A
INC ??             ; incrementa o registrador ??
CP ??              ; compara o Acumulador A com ??
HALT               ; para a CPU (fim)
JP label           ; salto incondicional para 'label:'

JR NZ, label       ; salta para 'label' se Z = 0
JR condição, label
condição:
   NZ → salto se Z = 0 (não zero)
   Z → salto se Z = 1 (zero)
   C → salto se carry = 1
   NC → salto se carry = 0

================== E/S =====================
LD A, $55
OUT ($10), A       ; envia para a porta 0x10

LD A, $12          ; valor a enviar
LD C, $10          ; porta 0x10
OUT (C), A         ; Envia o valor de A para a porta C
```

## Exemplos

### Z80

#### Soma de 5 + 3

```c
	LD A,05h        ; carrega 5 em A
	LD B,03h        ; carrega 3 em B
	CALL SOMA       ; chama a sub-rotina SOMA e o resultado estarah em A

	JP FIM          ; vai para o fim (loop)

;--------------------
; Sub-rotina de soma
; Entrada: A e B
; Saida:   A = A + B
;--------------------
SOMA:
	ADD A,B         ; soma A + B -> resultado em A
	RET             ; retorna para depois do CALL

;--------------------
FIM:
	JP FIM          ; Loop infinito para encerrar
```

#### Soma de 5 + 3 com Pilha

```c

LD SP,1FFh          ; Inicia o SP(Stack Pointer) em 1FF, topo da pilha na RAM.
					; A pilha incrementa para baixo
;--------------------
	LD A,05h        ; carrega 5(hexadecimal) em A
	LD B,03h        ; carrega 3(hexadecimal) em B
	CALL subr1      ; 

	JP FIM          ; vai para o fim

;--------------------
subr1:
	ADD A,B         ; soma A + B -> resultado em A
	CALL subr2
	RET             ; retorna para depois do CAL

;--------------------
subr2:
	ADD A, 3
	RET

;--------------------
FIM:
	HALT
```
