# Atomicidade de Banco de Dados Relacional

#ban

Princípio que sugere que as tabelas de um banco de dados relacional devem ser mais únicas entre si o possível, evitando a presença de campos que poderiam pertencer a outras tabelas ou que não compreendem à lógica da tabela original.
