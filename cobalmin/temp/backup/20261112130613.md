# Analisador Sintático Determinista

#com

(ou Analisador sintático LL(1), aparentemente) Dado um símbolo de entrada $a$ e uma variável $A$, a gramática deve possuir uma única produção que leve ao reconhecimento da cadeia iniciada em $a$. Deve haver uma única produção que reconheça o símbolo inicial $a$.

Gramáticas podem ser processadas por analisadores sintáticos preditivos se construídas de forma cuidadosa. Caso contrário, são processáveis por analisadores sintáticos não preditivos.

## Exemplos

1. Implementação de um reconhecedor preditivo:
 
```c
// gramatica
<cmd> → if <expr> then <cmd> else <cmd>
| if <expr> then <cmd>

<cmd> → if <expr> then <cmd> <cmd’>
<cmd’> → else <cmd>
| epsilon
```
