# SQL - Operação JOIN

#ban

Busca pelos valores em uma tabela a partir de determinadas condições. Todo valor que não tiver correspondência será `NULL`.

`INNER`: Valores que respeitam simultaneamente as condições, sem uma ordem específica de operandos. (intersecção dos dados)

**Ex**:
```sql
-- Traz apenas os usuario com reservas, juntamante das reservas
SELECT * FROM usuarios us -- Alias para especificar a tabela do ID
INNER JOIN reservas rs ON us.id = rs.id_usuario;
```

`LEFT`: Busca os dados da tabela da esquerda e detalha a correspondência destes dados com a tabela da direita.

**Ex**:
```sql
-- Tras todos os destinos e as reservas se tiverem
SELECT * FROM destinos des LEFT JOIN reservas rs ON des.id = rs.id_destino;
```

`RIGHT`: Análogo ao `LEFT JOIN`, porém com o foco nos dados da tabela da direita.

**Ex**:
```sql
-- Produz o mesmo resultado que a anterior
SELECT * FROM reservas rs RIGHT JOIN destinos des ON des.id = rs.id_destino;
```

`FULL`: Retorna todos os registros de todas as tabelas e detalha as correspondências entre ambos.
