# Algoritmo

#cal

Conjunto de instruções bem definidas, as quais esfecificam uma sequência de instruções para cada entrada, resultando em uma saída. Um algoritmo resolve um problema quando a saída é aceita/correta, mas isso não garante que ele seja verdadeiramente prático em termos de tempo e recursos gastos.
