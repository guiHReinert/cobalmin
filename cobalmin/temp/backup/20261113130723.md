# Set em Python

#python

Uma coleção não ordenada que não possui elementos duplicados. 

## Exemplos

```python
set(["abacaxi"]) # {"b","a","c","x","i"}
```

Os elementos não são indexados e podem ser obtidos somente por iteração em estruturas de repetição, da mesa forma que uma lista. Neste caso é mais interessante utilizar *enumerate()* no lugar de um simples *for-range()* para a criação dos índices a medida que o set é percorrido.
