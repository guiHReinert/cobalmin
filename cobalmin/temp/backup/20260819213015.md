# Bancos de Dados Não Relacionais

**Material**: [Oracle](https://www.oracle.com/database/nosql/what-is-nosql/)

Ou **NoSQL**: *Not Only SQL*.

Altamente flexíveis e projetados para lidar com um alto número de dados.

**Tipos**:

- **Key-Value**: Cada registro possui uma chave única.
	- **Ex**: [[20260819213128|Regis]].
- **Document**: Documentos semiestruturados, como JSON e BSON.
	- **Ex**: [[20260819213114|MongoDB]].
- **Colunas**: Dados organizados em colunas, útilpara certos tipos de consultas.
- **Grafo**: Quando os dados são tão importante quanto as suas conexões.
