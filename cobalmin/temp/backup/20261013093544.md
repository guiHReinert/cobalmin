# Thread

#sop

Ou lightweight process, é um fluxo de execução independente de processos a uma unidade básica de utilização da CPU.

Um erro em uma thread afeta todas as demais contidas no mesmo processo.

**Componentes**:

- ID de thread;
- Contador de programa;
- Conjunto de registradores;
- Pilha.
