# Comandos em Bash

<!-- ## Core Commands -->

## Listar Conteúdo do Diretório

```bash
ls              \\ conteudo da pasta atual
ls <DIR_NOME>   \\ conteúdo do DIR_NOME
ls -a           \\ exibe arquivos ocultos
ls -l           \\ exibe em formato de lista
ls -r           \\ exibe em ordem reversa
```

## Diretório Atual

```bash
pwd
\pwd
```

## Alterar Diretório

```bash
cd <DIR_NOME>
cd ..
cd /                        \\ volta para o diretorio raiz
cd ~                        \\ volta para a pasta pessoal
cd <DIR_NOME1>/<DIR_NOME2>
```

## Copiar Arquivos

```bash
cp <ARQ_NOME> <DIR_NOME>/
cp <ARQ_NOME1> <ARQ_NOME2>      \\ copia o arquivo e renomeia para <ARQ_NOME2>
cp -r <DIR_NOME1>/<DIR_NOME2>   \\ copia recursiva de diretorios    
cp -v                           \\ exibe detalhes da copia
```

## Mover ou Renomear Arquivos

```bash
mv 
```

## Criar Diretórios

```bash
mkdir 
```

## Remover Arquivos e Pastas

```bash
rm 
```

## Criar Arquivos Vazios

```bash
touch 
```

## Concatenar e Exibir Conteúdo

```bash
cat 
```

## Exibir Mensagens

```bash
echo
```
