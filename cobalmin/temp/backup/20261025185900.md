# Analisador Sintático

#com

Algoritmo com uma GLC própria que declara uma sequência de tokens identificáveis em um código-fonte para a análise sintática deste algoritmo. Foca principalmente nas frases gramaticais presentes no algoritmo, representáveis por árvores sintáticas para evidenciar e determinar a hierarquia de cada token.
