# Biblioteca Pandas

Biblioteca em Python expecializada em extrair, manipular e exportar um grande número de dados de arquivos de texto, Excel, CSV, SQL, etc, bem como para [[20260819213126|processos ETL]]. 

**Série**: Matriz unidimensional com sequência de valores que representam uma indexação.

**DataFrame**: Estrutura de dados tabular.

Considera-se `import pandas as pd` e `df` um instância do objeto `pd.DataFrame()`.

## Métodos e Atributos do Dataframe

`df.shape`: Retorna as dimenões do dataframe.

`df.info()`: Retorna o output do dataframe e o espaço ocupado por ele.

`df.columns()`: Retorna as colunas do dataframe. Pode receber uma lista para definir as colunas do dataframe pelos valores da lista.

`df.isnull().sum()`: Retorna a quantidade de dados vazios por coluna.

`df[<STR>].unique`: Retorna os valores únicos na coluna `STR`.

`df[<STR>].value_counts().plot(kind=bar)`: Plota um gráfico de colunas contendo os valores de `STR` e as suas quantidades. (é necessária a biblioteca **Matplotlib**).

`df.describe()`: Retorna dados estatísticos do dataframe.

```python
import pandas as pd

# URL com o arquivo CSV
url = <STR>	
df1 = pd.read_csv(url)

# Output dos dados importados
df1.head()
```
