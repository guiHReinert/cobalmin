# Arquitetura SPA - Single Page Applications

#ams

Tipo de sistema Web focado em compilar o código pelo navegador e apresentar a interface gráfica na mesma página. A troca de dados entre o site e o servidor é assíncrona e funciona como se fosse um software local: sem constantes recarregamentos da página principal, acelerando a interação com o usuário.
