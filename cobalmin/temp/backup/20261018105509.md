# SO - Sistema Operacional

#sop

O sistema operacional é uma camada de software entre o hardware e os programas que executam as tarefas para os usuários (OLIVEIRA; CARISSIMI; TOSCANI, 2001).

A sua função é fornecer aos prograas do usuário um modelo de computador melhor, mais simples e mais limpo, assim como lidar com o gerenciamento de todos os recursos (TANENBAUM, 2010).
