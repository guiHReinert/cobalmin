# Métodos de Sets em Python

#python

Sejam dois sets quaisquer *A* e *B*.

- `A.add(x)` adiciona o elemento x em A.
- `A.clear()` remove todos os elementos de A.
- `B = A.copy()` copia os elementos de A para B.
- `A.discard(x)` remove o elemento x, caso ele existir, de A e retorna x. 
- `A.remove(x)` remove o elemento x de A, possui retorno nulo e eleva uma exceção  caso x não estiver em A.
- `A.pop()` remove um elemento aleatório do conjunto.
- `A.len()` retorna o tamanho de A.

Outros métodos funcionam como operações entre conjuntos:

- `A.union(B)` une os sets A e B para um novo set.
- `A.intersection(B)` retorna a intersecção entre A e B para um novo set.
- `A.difference(B)` realiza a diferença de A com B.
- `A.symmetric_difference(B)` é a operação inversa à intersecção. Retorna os elementos que não fazem parte simultneamente a A e a B.
- `A.issubset(B)` retorna o booleano para caso A seja subconjunto de B.
- `A.issuperset(B)` é o inverso de *.issubset()*.
- `A.isdisjoint()` retorna o booleano para caso A e B não possuem nenhum elemento em comum
