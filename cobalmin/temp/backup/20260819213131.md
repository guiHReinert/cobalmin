## Testes A/B

Duas implementções de requisitos semelhantes "competem" entre si afim de medir e avaliar a interação e o comportamento dos usuários e relação a elas. Cada implementação é parecida com a outra, apenas com uma leve diferença, de modo que duas ou mais versões do sistema são geradas e distribuídas entre os usuários. A reação e comportamento dadas a essas implementeções são então comparadas e usadas como critério para definir qual versão foi melhor sucedida.

Testes A/N compreendem $n$ versões diferentes distribuídas entre os usuários.

Antes de realizar testes A/B deve-se executar um teste A/A para avaliar a diferença de recepção de uma versão nela mesma, e neste caso comumente se interpreta uma grande diferença como uma falha.
