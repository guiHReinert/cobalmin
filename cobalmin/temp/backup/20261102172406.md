# Ordenação em SQL

#ban

Organiza os dados com base em um critério.

## Exemplos

```sql
-- Lista os nomes em ordem alfabética
SELECT nome FROM usuarios ORDER BY nome;

-- Lista as duas colunas em ordem crescente e alfabética, respectivamente
SELECT nome, data_nascimento FROM usuarios
ORDER BY data_nascimento, nome;

-- Os nomes são listados na ordem contrária
SELECT nome, data_nascimento FROM usuarios
ORDER BY data_nascimento, nome DESC;
```
