# CMY

#cgr

Cyan-Magenta-Yellow. Sistemas subtrativo associado à absorção de cores, com variação de 0 a 1 ou 0 a 255. Na prática é inverso ao RGB;

| Cor | Red | Green | Blue 
| --- | --- | --- | --- |
| vermelho | 0 | 1 | 1 |
| verde | 1 | 0 | 1 |
| azul | 1 | 1 | 0 |
| amarelo | 0 | 0 | 1 |
| ciano | 1 | 0 | 0 |
| magenta | 0 | 1 | 0 |
| branco | 0 | 1 | 0 |
| preto | 0 | 0 | 0 |
| cinza $0<x<1$ | $1-x$ | $1-x$ | $1-x$ |

O sistema CMYK suporta também a cor preta para melhorar o contraste e economizar a tinta de impressoras.
