Bancos de dados relacionais são formados por **tabelas** ou entidades:

- **linhas**: tuplas/registros;
- **colunas**: atributos/características/propriedades/categorias. 

**Relacionamentos**: Associações entre entidades. Podem apresentar diferentes cardinalidades $(x,y)$, variando cada valor para $0,1,2,3,\dots,n$ associações, em DERs.

**índice**: Estrutura de endereçamento auxiliar.

**Chaves Primárias (\#chave)**: Identificadores únicos dos registros.

**Chave Primária Composta**: Quando é necessário duas chaves primárias para referenciar um único registro, ex: um CPF é único no país todo, porém um RG é repetível entre cidadãs de estados diferentes, então as chaves RG e Estado seriam chaves compostas para Pessoa.

**Chaves Estrangeiras (\&chave)**: Chaves que referenciam outros registros e indentificam relacionamentos, inclusive registros da mesma tabela.

**Transações ACID**:

| | |
| --- | --- |
| **A** | Atomicidade |
| **C** | Consistência |
| **I** | Isolamento |
| **D** | Durabilidade |

**MER e DER**: Modelo e Diagrama Entidade-Relacionamento, respectivamente.

- **Criação de DERs**: [Creately](https://app.creately.com), [QuickDBD](https://app.quickdatabasediagrams.com/#/)
