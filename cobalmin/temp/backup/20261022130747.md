# Operadores Bitwise da Linguagem C

Operam diretamente na forma binária dos inteiros operandos. 

| Operador                 | Símbolo     | Sintaxe         | Observação                                                                                        |
| ---------- | -------------------------------- | -------------------------------------------------------------------------------------------------- | -------------- |
| Bitwise AND              | &  | a & b  | Performs bit-by-bit AND operation and returns the result.                                          |
| Bitwise OR               | \| | a \| b | Performs bit-by-bit OR operation and returns the result.                                           |
| Bitwise XOR              | ^  | a ^ b  | Performs bit-by-bit XOR operation and returns the result.                                          |
| Bitwise First Complement | ~ | ~a    | Flips all the set and unset bits on the number.                                                    |
| Bitwise Leftshift        | << | a << b | Shifts bits to the left by a given number of positions; multiplies the number by 2 for each shift. |
| Bitwise Rightshift       | >> | a >> b | Shifts bits to the right by a given number of positions; divides the number by 2 for each shift.   |
