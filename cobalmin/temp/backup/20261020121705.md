# Token

#com

Equivalente a um símbolo, é uma unidade atômica definida pelas gramáticas de análise de um compilador. Representa uma entidade única, concatenável e mínima de um algoritmo, como um número, que podem produzir outros tipos de tokens mais específicos, como um inteiro, ponto flutuante, nome, função, etc.
