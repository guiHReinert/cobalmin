# Tipos de Sistemas Operacionais

#sop

## Monoprogramado / Monotarefa

Se concentra na execução de um único programa, tanto pelo processador quanto pela memória RAM. Os recursos são mal utiilizados, podendo deixar o sistema receoso, mas são de fácil implementação.

**Exemplos**:

- Geralmente sistemas embarcados;
- MS-DOS.

## Multiprogramado / Multitarefa

Múltiplos programas executados simultaneamente pelo sistema. Comumente requerem máquinas multicore.

### Tipos

Sistemas de Lote / Batch
Sistemas de Tempo Compartilhado / Time-Sharing
Sistemas de Tempo Real  /  Real-Time: Com tempo crítico de execução.
