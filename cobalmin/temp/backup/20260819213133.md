# SDBG Document

Um database Document é composto por múltiplas coleções, e cada coleção possui múltiplos documentos.

**Plataformas**: [[20260819213114|MongoDB]].

**Formatadores**: [JSON](https://jsonformatter.curiousconcept.com/).

**Coleção**: Agrupamento lógico de documentos, flexível, mas que não seja isenta de um sentido.

**Documentos**: BSON (Binary [[20260819213012|JSON]]).

- Nomeados por “`_id<NOME>`”;
- Compostos por pares chave-valor;
- Tamanho máximo de 16MB;
- Podem possuir aninhamentos de outros documentos.
- Tipos de dados simples:
	- String
	- Number
	- Boolean
	- Date
	- Null
	- ObjectId
- Tipos de dados complexos:
	- Array: `[]`.
	- Embedded Document.
		- **Denormalização de Documentos**: Inserir os dados de um documento em outro afim de facilitar processo ou poupar espaço. Casos estes dados forem acessados paralelamente, ou seja, um documento filho não precise do documento pai, então o ideal será manter-los separados.
	- GeoJSON.
	- Reference: Forma de relacionar os documentos entre si por meio de `ObjectiD()`.
		- **Ex**:
```json
{
	"_id": ObjeciId("123"),
	"destino": ObjectId("456"),
	"data": "2023-10-10",
	"status": "pendente",
	"usuario": ObjectId(345)
}
```
