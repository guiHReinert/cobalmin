# Arquitetura Harvard

#aoc

Possui 2 **memórias** **independentes**: uma para os programas, ou instruções, e outra para os dados gerados e armazenados pelo sistema. Cada memória se interliga **paralelamente** a um componente da Unidade de Controle por meio de 3 barramentos paralelos de dados, endereços e instruções.
A transferência das instruções permite *pipelining* paralelamente à transferência de dados para a unidade de controle e, uma vez que ambas as memórias são separadas, as transferências de instruções e de dados ocorrem simultaneamente em um único pulso de clock.

***Pipelining***: Enquanto uma instrução é decodificada, a próxima é lida pelo sistema simultaneamente.
