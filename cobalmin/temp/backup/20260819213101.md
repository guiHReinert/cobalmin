# Luigi Framework

Framework *open-source* para [[20260819213126|processos ETL]] com [[20260819213127|Python]] criado pelo *Spotify* para a criação de pipelines de dados. 

**Target**: Saída dos dados transformados por uma tarefa.

**Task**: Tarefas representadas pela classe `Task`.

- **Métodos**:
	- `require()`: Contém as instâncias de tarefas que precisam ser executadas antes da tarefa atual.
	- `output()`: O destino de onde a saída da tarefa será armazenada, logo um ou mais objetos de saída.
	- `run()`: Lógica real para executar uma tarefa.
