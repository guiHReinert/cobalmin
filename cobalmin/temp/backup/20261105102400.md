# Meta-Heurística

#cal

Técnica computacional usada para encontrar soluções satisfatórias para problemas NP-Difícil, onde algoritmos convencionais seriam impraticáveis. Não garante que a solução seja ótima, mas ela será ao menos eficiente e razoavelmente rápida.
