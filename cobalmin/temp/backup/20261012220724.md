# Clique de um Grafo

#teg

É um subconjunto $C \subseteq V$ de um grafo não direcionado $G = (V, E)$ tal que, para quaisquer dois vértices de $C$, há duas arestas os conectando. Portanto o subgrafo induzido de $C$ é um grafo completo.

**Clique maximal**: Um clique que não é subconjunto de nenhum outro clique maior.

**Clique máximo**: Maior clique de $G$. O número de clique $\omega(G)$ expressa a quantidade de vértices no clique máximo de $G$.

O seu oposto é um conjunto independente de vértices, logo não contém vértices adjacentes ou arestas em comum entre estes vértices.
