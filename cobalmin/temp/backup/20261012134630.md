# Árvore Binária

#eda2

Árvore de grau 2. Utilizada para algoritmos de busca binária.

Uma árvore binária ordenada crescente organiza os valores de seus nodos da seguinte forma: o nodo da esquerda recebe um valor menor que o do pai, enquanto o da direita recebe um valor maior.

**Representação em C**:
```c
typedef struct no {
	struct no* pai;        //ponteiro para o nó pai
	struct no* esquerda;   //ponteiro para o nó filho a esquerda
	struct no* direita;    //ponteiro para o nó filho a direita
	float v;               //conteúdo de um nó arbitrário da árvore
} No;

typedef struct arvore {
	struct no* raiz;
} Arvore;
```

## Algoritmos de Busca

Buscam a chave na sua **primeira** ocorrência na árvore binária. Ambos os algoritmos seguem a ordem da esquerda para a direita de nodo a nodo, ou caminho a caminho. Possui variações de estratégias quanto à visitação dos nodos:

- ***Pre-Order***: **Raiz** -> Direita -> Esquerda
- ***In-Order***: Esquerda -> **Raiz** -> Direita
- ***Pos-Order***: Esquerda -> Direita -> **Raiz**

### Busca Em Profundidade (Depth-First Search)

Percorre a árvore pela sua profundidade passando por um nodo a cada nível. Quando um caminho for competamente percorrido, o algoritmo seguirá para uma nova iteração pelo próximo caminho disponível.

### Busca em Largura (Breadth First Search)

Percorre a árvore em um nível completo antes de avançar para o próximo. Uma vez que o encadeamento dos nodos não é diretamente usado, é necessário conhecer todos os nodos que compõem um mesmo nível.

## Balanceamento

 Uma árvore balanceada é aquela que possui altura semelhante tanto na subárvore esquerda quanto na direita, com diferença de apenas 1 nodo no máximo.
	
 **Fator de Balanceamento**:
$$
FB = altura-arvore-esquerda - altura-arvore-direita
$$

O balanceamento é realizado a partir das operações de rotação em seus nodos para qualquer $FB$ diferente de $-1$, 0 ou 1:

**Rotação Simples**:

- **RSE - Rotação simples à esquerda**: Árvore mais alta/prounda no lado direito.
- **RSD - Rotação simples à direita**: Árvore mais profunda no lado esquerdo.

**Rotação Dupla**:

- **RDE - Rotação dupla à esquerda**: Nodo com $FB$ negativo e o seu filho com $FB$ positivo.
- **RDD - Rotação dupla à direita**: Nodo com $FB$ positivo e o seu filho com $FB$ negativo.

### Árvore Degenerada

Cada nodo possui uma única árvore subárvore associada, apresentando então uma estrutura linear (logo a sua complexidade de percorrimento será linear, $N$).

### Árvore Cheia

Balanceamento perfeito de uma árvore, logo todos os seus nodos possuem exatamente 2 filhos ou 2 folhas. Possui complexidade de percorrimento $log(N)$.

## Árvore AVL

Árvore altamente auto-balanceada: a cada opetação de inserção ou exlcusão deve-se realizar uma operação de balanceamento.
