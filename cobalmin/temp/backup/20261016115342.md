# Argumentos de Linha de Comando em main()

A função `main()` pode receber os parâmetros `int argc` e `char* argv[]` como parâmetros respectivos a argumentos passados durante a execução do algoritmo que a contiver. `argc` diz respeito à quantidade de argumentos e `argv` contém os argumentos como uma única string.

**Exemplo**: caso `main()` estiver no arquivo `main`

```c
#include <stdio.h>
int main(int argc, char* argv[]) {
  	printf("The value of argc is %d\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("%s \n", argv[i]);
    }
    return 0;
}
```

, na execução do terminal,

```
$ ./main geeks for geeks
The value of argc is 4
./teste 
geeks 
for 
geeks 
```
