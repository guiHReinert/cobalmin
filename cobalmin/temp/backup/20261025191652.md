# Árvore Sintática

#com

Árvore de derivação usada para a aplicação de análise sintática. Pode ser formada a partir de uma análise sintática da compilação de um algoritmo, onde cada frase gramatical irá gerar uma árvore sintática própria, onde os nós folha representam tokens terminais e os nós internos representam os tokens de operação.
