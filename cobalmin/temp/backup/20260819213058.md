# Isomorfismo para Grafos

#teg

Dois grafos $G_1 = (V_1, A_1)$ e $G_2 = (V_2, A_2)$ são isomorfos, i.e., $G_1 \simeq G_2$, se existe uma [[20260819213048|função bijetora]] $f : V_1 \rightarrow V_2$ tal que $(u, v) \in A_1$ se e só se $(f(u), f(v)) \in A_2$. Portanto seus vértices são mapeáveis entre si e possuem arestas semelhantes, apesar deles potencialmente serem estruturalmente diferentes. 

**Condições Suficientes Para um Isomorfismo em Grafos**: Portanto não conclusivas:
	a) O mesmo número de vértices e arestas;
	b) A mesma sequência gráfica;
	c) Se o $G_1$ usa os vértices $v_1, v_2, v_3,... v_k$ para criar um ciclo de comprimento $k$, então, seu isomorfo $G_2$ também deve usar $f(v_1), f(v_2), f(v_3),... f(v_k)$ para criar um ciclo de mesmo comprimento $k$;
	d) Se um grafo é de uma certa família (bipartido, etc.), o seu isomorfo também será.

## Autovalores e Autovetores

Seja $W$ um espaço vetorial, o escalar $\lambda$, ou **autovalor** de um operador linear $A: W \rightarrow W$, é tal que se existir um vetor $x$ diferente de zero onde $Ax = \lambda x$, o vetor $x$ será chamado **autovetor** do autovalor $\lambda$.

Os autovalores de uma matriz quadrada $A_{n,n}$ são os $n$ elementos que caracterizam as propriedades mais importantes desta matriz. Ou seja, as matrizes de adjacência de dois grafos quaisquer $G_1$ e $G_2$ que possuírem os **mesmos autovalores** por consequência caracterizaram ambos os grafos como isomorfos.
