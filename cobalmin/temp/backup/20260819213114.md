# MongoDB

**Material**: [Modelagem de documentos](https://www.luiztools.com.br/post/padroes-para-modelagem-de-dados-documentos-em-mongodb/)

**Formatadores**: [JSON](https://jsonformatter.curiousconcept.com/).

Plataforma baseada em Javascript para o tratamento de bancos de dados [[20260819213015|NoSQL]] do tipo [[20260819213133|Document]].

Um database sem nenhuma coleção não aparecerá no MongoDB.

## Operações

Toda operação é cincundado por `{}`.

### Inicialização
```js
// Cria ou transfere para o database
use viagens;

// Cria as coleções
db.createCollection("usuarios")
db.createCollection("destinos")

// Ou vc pode inserir diretamente um documento e ele já ira criar a collection
db.usuarios_novo.insertOne({});
```

### insert*()

Utilizado pela [[#projeo|projeção]] do database.

`insertOne()`: Adiciona 1 novo registro.

**Ex**:
```js
// Inserindo o primeiro documento
db.usuarios.insertOne(
    {   
        "nome": "nome",
        "data_nascimento": "1990-10-05",
        "email": "pamela.apolinario.borges@gmail.com",
        "endereco": "Av Manoel Marques de Jesus, 380 - Vila Xavier, Araraquara/SP"
    });
db.destinos.insertOne({"nome":"Praia do Rosa", "descricao":"Linda praia"})
```
`insertMany()`: Adiciona múltiplos registros.

**Ex**:
```js
// Inserir documentos na coleção "usuarios"
db.usuarios.insertMany([
   {
      "nome":"João",
      "idade":25,
      "cidade":"São Paulo",
      "estado":"SP",
      "endereco":{
         "rua":"Avenida Principal",
         "numero":123,
         "cidade":"São Paulo",
         "estado":"SP"
      }
   },
   {
      "nome":"Maria",
      "idade":30,
      "cidade":"Rio de Janeiro",
      "estado":"RJ",
      "endereco":{
         "rua":"Rua Secundária",
         "numero":456,
         "cidade":"Rio de Janeiro",
         "estado":"RJ"
      }
   }
]);
```

### find*()

`find()`: Encontra todos os registros com o critério.
**Ex:**
```js
db.usuarios.find({"nome": "João"});

// Retorna todos os tados da collection
db.usuarios.find({});
```
`findOne()`: Retorna a primeira referência do critério de busca.

**Ex**:
```js
db.usuarios.findOne({"nome": "João"});
```
`findOneAndUpdate()`: Encontra a primeira referência da busca, atualiza, e retorna o estado anterior do registro.

**Ex*:*
```js
db.usuarios.findOneAndUpdate({ nome: "João" }, { $set: { idade: 26 } });
```
`findOneAndDelete()`: Encontra, deleta e retorna a primeira referência da busca.

**Ex**:
```js
db.usuarios.findOneAndDelete({ nome: "João" });
```

### delete*()

`deleteOne()`: Deleta o primeiro registro a partir da condição de consulta.

`deleteMany()`: Deleleta todos os registros a partir da condição de consulta.

```js
// Usando o método deleteOne() para excluir o primeiro documento que corresponde ao filtro especificado
db.usuarios.deleteOne({ nome: "João" });

// Usando o método deleteMany() para excluir todos os documentos que correspondem ao filtro especificado
db.usuarios.deleteMany({ cidade: "São Paulo" });
```

### update*()

`updateOne()`:
```js
db.usuarios.updateOne(
  { nome: "João" },
  { $set: { idade: 26 } }
);
```
`updateMany()`:
```js
db.usuarios.updateMany(
  { cidade: "São Paulo" },
  { $set: { estado: "SP" } }
);
```

```js
// Usando o operador $set para definir o valor de um campo específico
db.usuarios.updateOne({ nome: "João" }, { $set: { idade: 26 } });

// Usando o operador $inc para incrementar o valor de um campo numérico
db.usuarios.updateOne({ nome: "João" }, { $inc: { idade: 1 } });

// Usando o operador $rename para renomear um campo existente
db.usuarios.updateOne({ nome: "João" }, { $rename: { "endereco.rua": "endereco.nomeRua" } });

// Usando o operador $unset para remover um campo específico de um documento
db.usuarios.updateOne({ nome: "João" }, { $unset: { endereco: "" } });

```

### replaceOne()

```js
db.usuarios.replaceOne(
  { nome: "João" },
  {
    nome: "John",
    idade: 27,
    cidade: "São Paulo",
    estado: "SP",
    endereco: {
      rua: "Avenida Principal",
      numero: 123
    }
  }
);
```

## Operadores

### Lógicos

`$and`: Operações contidas em arrays `[z, y, x, ...]` também contam como operandos de um `and`.

**Ex**:
```js
db.usuarios.find({ $and: [{ idade: { $gte: 18 } }, { cidade: "São Paulo" }] });
```
`$or`:
```js
db.usuarios.find({ $or: [{ idade: { $lt: 18 } }, { cidade: "Rio de Janeiro" }] });
```
`$not`:
```js
db.usuarios.find({ idade: { $not: { $eq: 25 } } });
```

### Comparação

`eq`: *equal*.
```js
// O caractere ":" também chama este operador
db.usuarios.find({endereco.cidade:"São Paulo"}) // Case sensitive
db.usuarios.find({ idade: { $eq: 25 } });
```
`ne`: *not equal*.
```js
db.usuarios.find({ idade: { $ne: 30 } });
```
`gt`: *bigger than*.
```js
db.usuarios.find({ idade: { $gt: 30 } });
```
`gte`: *bigger or equal to*.
```js
db.usuarios.find({ idade: { $gte: 30 } });
```
`lt`: *smaller than*.
```js
db.usuarios.find({ idade: { $lt: 30 } });
```
`lte`: *smaller or equal to*.
```js
db.usuarios.find({ idade: { $lte: 30 } });
```
`in`.
```js
db.usuarios.find({ cidade: { $in: ["São Paulo", "Rio de Janeiro"] } });
```
`nin`: *not in*.
```js
db.usuarios.find({ cidade: { $nin: ["São Paulo", "Rio de Janeiro"] } });
```

## Projeção

Quais campos devem ser retornados em uma busca.

**Ex**:
```js
// Lista os nomes e idades de todos os usuários
db.usuarios.find({}, { nome: 1, idade: 1 })
```

---

## Ordenação

A ordem crescente é selecionada por “`1`”, enquanto a descrescente por “`-1`”.

**Ex**:
```js
db.usuarios.find().sort({ idade: 1 })

// Ordena primeiramente pela idade e depois pelo nome
db.usuarios.find().sort({ idade: 1 , nome: 1})
```

---

## Limitação

Limita os resultados de uma busca.

**Ex**:
```js
db.usuarios.find().limit(10)
```

---

## Paginação

Segmenta os resultados de uma busca.

**Ex**:
```js
db.usuarios.find().skip(10).limit(5)
```
