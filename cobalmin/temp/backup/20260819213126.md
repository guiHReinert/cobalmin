# Processos ETL

Ou ***Extract, Transform and Load***, é um tipo de *data integration* com a função de padronizar ou manipular os dados que venham de diferentes sistemas para outros sistemas ou comumente uma núvem. Útil para compor uma *data warehouse*. É utilizada amplamente a linguagem Python para estes processos.

A transformação dos dados também envolve a llimpeza, racionalização e complementação desses dados.

## Etapas

### Extração

Captura dos dados a partir de outros sistemas ou arquivos (CSV, JSON, etc.). É na extração que começa a *staging area*, antes de partir para a transformação.

### Transformação

Adapta os dados que vieram de outro sistema para servir ao atual, resumidamente.

### Carregamento

Lê e aplica/implementa os dados gerados. A sua apresentação é chamada *dashboard*.
