# Classes de Complexidade de Problemas

#cal

Atualmente as classes de problemas seguem a hierarquia de complexidade

$$
L \subseteq NL \subseteq P \subseteq NP \subseteq PSPACE \subseteq EXPTIME \subseteq NEXPTIME \subseteq EXPSPACE
$$

, logo, por exemplo, todo problema $\text{O}(\log{n})$ poderia ser resolvido por algoritmos para complexidades maiores como $NP$, mas nem todo problema $NP$ pode, em teoria, ser resolvido por um algoritmo de mu problema $P$. Tal discordância gera um problema conhecido como a Questão $NP$ vs $NP\text{-}Completo$.
