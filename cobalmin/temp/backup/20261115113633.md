# Comandos para Commits em Git

Comandos aleatórios para operações básicas para Git

- `git status` informa a situação atual referente aos commits pendentes e alterações detectadas no repositório local.
- `git log` lista todos os commits feitos no repositório
- `git reflog` lista as referências de todos os commits realizados no repositório, inclusive os commits que foram excluidos por `git reset` ou demais comandos.

- `git fetch` apenas coleta os commits pendentes do repositório remoto para o local.
- `git pull` coleta os commits pendentes do repositório remoto E atualiza os arquivos do local. Se o repositório local apresentar commits pendentes paralelos aos do remoto deverá ser feito um *merge* ou um *stash* ***(?)***.
- `git checkout <HASH_COMMIT> .` retorna para o commit de código `HASH_COMMIT`.
