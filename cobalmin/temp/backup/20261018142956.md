# Shell

#sop

Programa que interpreta comandos digitados em terminais de SO derivados do Unix, funcionando como uma interface entre o SO e o usuário.

## Tipos

- **bash**: Bourne Again Shell, padrão do Linux
- **zsh**: Z Shell, padrão do macOS
- **sh**: Shell original do Unix
- **fish**: Friendly Interactive Shell
- **PowerShell**: padrão da Microsoft
