# Terceira Forma Normal de Banco de Dados

#ban

 Nenhuma coluna não-chave pode depender de outra coluna não-chave da mesma tabela. Ela é opcional, mas a sua utilização ou não depende do bom senso.

 Eliminar dependências funcionais transitivas (vulgarmente significa que uma ou mai scolunas de uma tabela dependem de uma coluna desta tabela, como um ID que poderia ser transferido para uma tabela a parte, logo estas demais colunas também seriam inseridas nesta nova tabela).
