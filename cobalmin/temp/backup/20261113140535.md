# String em C

#c

Toda string é uma aray de chars terminada com o caracter nulo `'\0'`.

## Exemplos

1. Declaring a string with a maximum space of 9 characters

```
char frase[9];
```

2. Declaring a string with a maximum space of i characters

```
int i;
char phrase[i];
```
