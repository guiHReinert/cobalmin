# .gitignore

Arquivo de texto com os endereços dos diretórios desconsiderados por todas as operações de commit. Existem comandos criados para editar o arquivo, porém ele também pode ser editado diretamente pelo usuário.

- `echo <DIRETORIO\> > .gitignore` insere o `DIRETORIO` dentro de `.gitignore`.
- `echo > .gitignore` esvazia `.gitignore`.
