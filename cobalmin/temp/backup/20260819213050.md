# Comando stash em Git



## Exemplos

- `git stash` arquiva as alterações para que elas não sejam incluídas no próximo commit
- `git stash list` lista todas as alterações arquivadas na pilha
- `git stash pop` remove a alteração arquivada mais recente da pilha e a registra
- `git stash apply` inlcui aos commits contidos na pilha na lista de alterações mas sem os retirar da pilha (?)
