# Tipos em C

#c

- `int` (2-4 bytes);
- `float` (4 bytes);
- `double` (8 bytes);
- `char` (1 byte);
- Array;
- [[20261113140258|Arrays em C]]
- String;
- [[20261113140535|String em C]]

## Exemplos

1. Notation for big or small numbers:

```
24,000 == 24e3 == 24E3
0.0024 == 24e-3 == 24E-3
```

2. Keyword for the variable manipulation:

`const int`, `const double`, `const char`, ... Defines the variable as constant on the code.
