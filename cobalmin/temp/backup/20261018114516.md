# Estrutura de um Sistema Operacional

#sop

1. Os recursos de mais baixo nível do hardware são gerenciados pelo núcleo, que é carregado e iniciado pelo boot code;
2. O boot code também reconhece, testa e configura os dispositivos de hadware;
3. Os periféricos, módulos de E/S físicos como discos rígidos SATA, portas USB e placas gráficas são gerenciadas pelos drivers;
4. Os programas utilitários são as ferramentas que complementam o núcleo facilitando tarefas como formatação de discos, configuração de dispositivos e manipulação de arquivos, e fornecem interfaces gráficas e terminais.
