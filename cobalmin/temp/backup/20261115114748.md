# Comando reset em Git

- `git reset --soft <HASH_COMMIT>` remove todos os commits realizados após o commit de código/hash `HASH_COMMIT` e lista todas as suas alterações na *staging area* do git. Útil para reunir vários commits em um só, pois o próximo commit a ser feito irá realizar todas as mudanças organizadas pelo comando.
	- `git reset -soft HEAD~5; git commit` combina os 5 últimos commits em um único commit.
- `git reset --mixed <HASH_COMMIT>`**(padrão)** reúne todos os arquivos que apareceram após o commit de hash `HASH_COMMIT` para a árvore de trabalho, sem que o staging area do git os reconheça.
- `git reset --hard <HASH_COMMIT>` retorna ao commit de hash `HASH_COMMIT` e **exclui permanentemente** todos os commits posteriores.

Dentro da pasta `.git`:

- `cat config` detalha os parâmetros de configuração do repositório.
