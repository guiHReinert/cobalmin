# Arquitetura Von Neumann

#aoc

É amplamente utilizada pelos computadores convencionais e possui uma formação mais simples do que a de Harvard, apesar de ser mais lenta dada a ocorrência do **Gargalo de Von Neumann**. Esta arquitetura possui um **único** **barramento** de transferência dos dados, endereços e instruções, bem como uma **única** **memória** (memória principal) que armazena tanto os programas quanto os demais dados.

Ela apresenta cinco principais componentes para o funcionamento do sistema (Máquina de Von Neumann):

- **Unidade de Entrada**: Input de dados, como a interação humano-máquina.
- **Unidade de Saída**: Output dos dados.
- **Unidade de Controle**: Contida na CPU.
- **Unidade Lógica e Aritmética**: Contida na CPU.
- **Unidade de Memória**: Memória interna.

**Gargalo de Von Neumann**: Uma vez que a arquitetura de Von Neumann compartilha o mesmo barramento entre a CPU e a memória principal para instruções e dados, são necessários **2 ciclos de clock** para primeiramente transferir uma **instrução** da memória, e um segundo pulso para transferir os **dados** para dentro ou para fora da memória. 

A unificação das memórias representou uma **inovação** quanto ao modelo anterior. Ao invés dos programas serem registrados diretamente no hardware e então lidos pela CPU, eles começaram a serem tratados como dados e modificáveis pelo próprio software.

**Execução de um Programa**: O computador lê o primeiro endereço contendo o programa, depois a primeira instrução que será decodificada e executada. A execução dita se deverá ser armazenado algum dado, senão o processo seguirá para a próxima instrução, e assim por diante.
