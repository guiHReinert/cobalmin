# Branch em Git

Análogo à estrutura de dados árvore, uma branch é um ponteiro de um nodo commit da árvore de commits de um repositório. Inicialmente, um repositório é inicializado com a branch principal "main", ou qualquer outro nome escolhido, e uma ramificação da principal fará com que os novos commits lançados serão separados para cada branch. As operações `git commit`, por padrão, irão atualizar a branch principal, porém, caso seja especificado outra branch do repositório, este commit irá compor somente esta outra branch, no lugar da branch principal.
