# OpenGL - Open Graphics Library

#cgr

É uma framework de comunicação entre o sistema operacional e o hardware gráfico desenvolvida em 1992 para a aplicação de funções gráficas 2D e 3D. Independe do SO ou hardware, porém são válidos apenas poĺigonos simples e convexos e curvas podem ser aproximadas por retas. Possui múltiplas variações de implementação.
